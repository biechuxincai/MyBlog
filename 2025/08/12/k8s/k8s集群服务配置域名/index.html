    🧩 9. 常见坑（强烈建议看一遍）

    ❌ DNS 不生效

    ➡️ 域名没解析到 Node IP
    ➡️ 或本地 DNS 缓存

    ❌ 404 Not Found

    ➡️ IngressClassName 必须为 nginx
    ➡️ host 必须和访问的域名一致

    ❌ 返回 default backend

    ➡️ NodePort 端口没开放（需要关闭防火墙或允许端口转发）

    ❌ HTTPS 证书错误

    ➡️ 自签证书必须 CN=SNI 域名一致

    ❌ Ingress Controller 处于 Completed 状态

    ➡️ 不是 controller，是 job（patch / create job）正常现象。
